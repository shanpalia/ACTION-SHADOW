# ACTION SHADOW

**By ShanPalia** — an original Android-first 2.5D action-shooter prototype made with Godot 4.

## Current prototype
- Side-view 3D scene with depth layers and stage color themes
- Player movement, jump and energy projectiles
- Mobile touch controls plus keyboard controls
- Five stage themes, enemies and a simple stage boss
- Offline single-player; no login or internet required

## Open in Godot
1. Install Godot 4.x.
2. Import `project.godot` in Godot Project Manager.
3. Press F6/F5 to run the main scene.

Controls: A/D or arrow keys to move, Space to jump, J or left mouse button to fire. Touch controls appear on screen for mobile.

## Important status
This is an early prototype/source upload, not a finished commercial game. Character models, animations, sound, unique boss behaviors, menus, balancing, Android export configuration and device testing still need work. The repository does not yet contain a verified APK.
